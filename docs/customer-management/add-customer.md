# Add Customer

The Add Customer functionality allows users to create a new customer record in the Hexa Billing System.

![Add New Customer](/img/add-customer.png)

*Figure: Add New Customer form used to enter and create a new customer record.*

## Adding a Customer

1. Open **Customer Management**.
2. Select the option to add a new customer.
3. Enter the required customer information.
4. Review the entered information.
5. Save the customer record.

## Purpose

Adding customers allows the system to maintain an up-to-date customer database and ensures that new customers can be managed through the billing system.
