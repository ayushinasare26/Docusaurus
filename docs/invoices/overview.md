# Invoices

## Overview

The Invoices section allows users to view, process, manage, and download invoice records for customers in the Hexa Billing System.

The section provides access to both regular invoices and manually created invoices.

### Invoice Types

The Invoices section contains two types of invoices:

1. **Regular Invoices** – Used to view and process invoices generated through the regular billing process.
2. **Manual Invoices** – Used to create and manage invoices that are entered manually.

These options allow users to manage different invoice requirements within the billing system.
