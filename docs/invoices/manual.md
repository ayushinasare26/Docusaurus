# Manual Invoices

The Manual Invoices section allows users to view and manage invoice records that are created manually in the Hexa Billing System.

![Manual Invoices](/img/invoice-manual.png)

*Figure: Manual Invoices interface showing manually created invoice records, search and filtering options, and available actions.*

## Invoice Controls

The Manual Invoices section provides controls for viewing and managing manually created invoices.

### View Monthly Invoices

Users can select a month to filter and view the corresponding manual invoice records.

### Search

The search field allows users to search for invoices using the customer name or customer ID.

### Create Manual Invoice

The **Create Manual Invoice** option allows users to create a new invoice manually.

### Download All

The **Download All** option allows users to download the available manual invoice records.

## Invoice Information

The manual invoice table displays information such as:

- Customer ID
- Customer name
- Invoice number
- Invoice date
- Due date
- VAT percentage
- Invoice total

The table also provides actions for individual invoice records.

## Invoice Actions

Users can perform actions on individual manual invoices.

### Download

Users can download an individual invoice using the **Download** button.

### Delete

Users can delete an individual manual invoice using the **Delete** button.

## Purpose

The Manual Invoices section helps users:

- View manually created invoices.
- Create new manual invoices.
- Search invoice records.
- Download individual invoices.
- Download multiple invoices.
- Delete manual invoices when required.
- Review invoice details and totals.
