# Regular Invoices

The Regular Invoices section displays invoice details for customers in the Hexa Billing System.

It allows users to view monthly invoices, process invoices, send invoice emails, download invoices, delete invoices, and push invoices to Xero.

![Regular Invoices](/img/invoice-regular.png)

*Figure: Regular Invoices interface showing invoice records, processing options, customer information, invoice dates, and totals.*

## Invoice Controls

The Regular Invoices section provides several controls for managing invoice records.

### View Monthly Invoices

Users can select a specific month to view the corresponding invoice records.

### Process Invoices

The **Process Invoices** option allows users to process the displayed invoice records.

### Send Emails

Users can select invoice records and use the **Send Emails** option to send invoices through email.

### Download

The **Download** option allows users to download selected invoice records.

### Delete

The **Delete** option allows users to remove selected invoice records from the list.

### Push All to Xero

The **Push All to Xero** option allows invoice records to be pushed to the connected Xero system.

## Invoice Information

The invoice table displays information such as:

- Customer ID
- Customer name
- Contact person
- Invoice number
- Invoice date
- Invoice total

Users can select individual invoices using the checkboxes provided in the table.

## Search

The search field allows users to search for invoices using the customer name or customer ID.

## Purpose

The Regular Invoices section helps users:

- View customer invoice records.
- Process invoices.
- Send invoices to customers.
- Download invoice information.
- Delete invoice records when required.
- Push invoice data to Xero.
- Search and review invoice information.
