# Payments

The Payments section allows users to view and manage customer payment records in the Hexa Billing System.

![Payments](/img/payments.png)

*Figure: Payments screen displaying customer payment records, payment dates, amounts, payment types, service types, and processing status.*

## Payment Information

The Payments table displays important payment details, including:

- Customer ID
- Customer Name
- Payment Date
- Amount
- Payment Type
- Service Type
- Status
- Available actions

## Payment Filters

Users can filter payment records using:

- Payment Type
- Service Type
- Status
- From Date
- To Date

These filters help users locate specific payment records.

## Searching Payments

The search option allows users to search payment records using customer information.

Users can select the search criteria and enter the required search value.

## Payment Status

The **Status** field indicates the current processing state of a payment.

For example, payments may appear as:

- Processed
- Unprocessed

## Payment Actions

The Actions column provides an **Edit** option for managing existing payment records.

## Add Payment

The **Add Payment** option allows users to create a new payment record.

## Purpose

The Payments section helps users track customer payments, review payment status, and maintain accurate payment records.
