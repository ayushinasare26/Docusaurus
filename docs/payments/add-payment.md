# Add Payment

The Add Payment functionality allows users to create a new payment record in the Hexa Billing System.

![Add Payment](/img/add-payment.png)

*Figure: Add New Payment form used to enter customer payment information.*

## Payment Information

The Add New Payment form allows users to enter the following information:

- Customer
- Payment Date
- Amount
- Payment Type
- Service Type
- Comments

## Adding a Payment

To add a new payment:

1. Open the **Payments** section.
2. Select **Add Payment**.
3. Search for and select the required customer.
4. Enter the payment date.
5. Enter the payment amount.
6. Select the payment type.
7. Select the service type.
8. Add optional comments if required.
9. Select **Add Payment** to save the record.

## Required Fields

The form requires the following information:

- **Customer**
- **Payment Date**
- **Amount**
- **Payment Type**
- **Service Type**

Required fields are marked with an asterisk (*).

## Comments

The **Comments** field can be used to add optional notes related to the payment.

## Cancelling

The **Cancel** button allows users to close the form without adding the payment.

## Purpose

The Add Payment functionality provides a simple way to record customer payments and maintain accurate billing information.
