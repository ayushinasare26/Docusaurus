# Reports

## Overview

The Reports section allows users to generate business reports based on different report types and billing periods.

![Reports](/img/reports.png)

## Generate Report

The **Generate Report** section provides the options required to generate a report.

### Report Type

Users can select the required report type from the dropdown.

The example shown in the system is:

**Customer Invoice Report (NORMAL)**

### Month

Select the month for which the report needs to be generated.

### Year

Select the required year.

## Generate Report Button

After selecting the report type, month, and year, click **Generate Report**.

The system generates the requested report based on the selected parameters.

## Purpose

The Reports module provides a centralized way to generate billing and customer-related reports for a selected period.
