# Recent Uploads

The Recent Uploads section displays information about recently uploaded CDR files.

![Daily CDR Sync](/img/cdr-daily-sync.png)

*Figure: Daily CDR Sync History showing execution status, processed records, inserted records, and synchronization details.*

## Upload Information

Users can review recently uploaded files and check their processing status.

This provides visibility into CDR upload activity and helps users identify successfully processed or problematic uploads.

## Purpose

Recent Uploads helps users:

- Review uploaded CDR files.
- Check upload activity.
- Monitor processing status.
- Identify files that may require further attention.
