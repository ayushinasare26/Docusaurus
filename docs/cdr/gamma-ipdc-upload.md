# Gamma IPDC Upload

The Gamma IPDC Upload section is used to upload Gamma IPDC Call Detail Record data into the Hexa Billing System.

![Gamma IPDC Upload](/img/gamma-ipdc-upload.png)

*Figure: Gamma IPDC upload interface for selecting the year, month, file type, and uploading IPDC CSV data.*

## Upload Process

1. Open the **CDR** section.
2. Select the **Gamma IPDC** upload option.
3. Select the required file.
4. Upload the file.
5. Allow the system to process the uploaded data.
6. Review the upload result.

## Purpose

This functionality allows Gamma IPDC call data to be imported into the system for further processing, billing, and reporting.
