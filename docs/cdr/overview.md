# Call Detail Records (CDR)

## Overview

The Call Detail Records (CDR) section is used to manage and review call-related records in the Hexa Billing System.

CDR data contains information about calls processed by the system and can be used for billing, analysis, and reporting.

## CDR Management

The CDR section allows users to work with call records and uploaded CDR files.

Users can review uploaded records and verify that the required data has been successfully processed.

## Purpose

The CDR module helps users:

- Manage call detail records.
- Upload CDR data.
- Review uploaded files.
- Validate CDR information.
- Support accurate billing and reporting.
