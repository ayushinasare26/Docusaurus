# Export CDR

The Export CDR feature allows users to export Call Detail Records based on selected customers and a specified date range.

![Export CDR](/img/cdr-export.png)

*Figure: Export CDR interface for selecting customers and a date range before downloading CDR data.*

## Exporting CDR Data

Users can:

- Select a customer or all customers.
- Select the required date range.
- Download the CDR data as a CSV file.

## Purpose

The Export CDR feature makes it easier to retrieve and analyze call records outside the billing system.
