# Import CDR

The Import CDR functionality allows users to upload Call Detail Record files into the Hexa Billing System.

![Import CDR](/img/cdr-import.png)

*Figure: CDR import interface for selecting the year, month, DIDs, and uploading CDR files.*

## Uploading a CDR File

1. Open the **CDR** section.
2. Select the CDR import option.
3. Choose the required CDR file.
4. Upload the file.
5. Wait for the system to process the uploaded data.
6. Review the upload result.

## Purpose

Importing CDR data allows the system to process call information that can be used for billing and reporting.
