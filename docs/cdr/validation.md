# CDR Validation

CDR Validation is used to verify uploaded Call Detail Record data before it is used for further processing.

## Validation

The system checks the uploaded CDR data to identify information that may be invalid, incomplete, or inconsistent.

## Purpose

Validation helps:

- Identify incorrect CDR data.
- Detect incomplete records.
- Reduce data-processing errors.
- Improve the accuracy of billing information.

## Review

After uploading a CDR file, users should review the validation result and resolve any identified issues before continuing with further processing.
