# Users

## Overview

The Users section is used to manage system users and their login credentials.

The system uses **Email and Password via Cognito** for user authentication.

![Users](/img/users.png)

## User Information

The user list displays information including:

- Email Address
- Status

## Search

Users can search for a system user using their email address.

The search controls include:

- Search by Email
- Search field

## User Status

The status column displays the current status of the user account.

If no matching users are found, the system displays a **No results found** message.

## Purpose

The Users module provides centralized management and lookup of system users and their authentication status.
