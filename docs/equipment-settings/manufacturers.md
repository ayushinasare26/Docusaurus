# Manufacturers

## Overview

The Manufacturers section is used to manage equipment manufacturers and their contact information.

![Manufacturers](/img/manufacturers.png)

## Manufacturer Information

The manufacturer list contains:

- ID
- Manufacturer Name
- Contact Number
- Email
- Website
- Status
- Actions

The system displays the current status of each manufacturer.

## Search

Users can search for a manufacturer by name using the search functionality.

## Add Manufacturer

The **Add Manufacturer** button allows users to create a new manufacturer record.

## Edit Manufacturer

The **Edit** action allows users to update manufacturer information.

## Delete Manufacturer

The **Delete** action allows users to remove a manufacturer record.

## Purpose

The Manufacturers module maintains manufacturer information that can be associated with network equipment in the system.
