# Equipment

## Overview

The Equipment section is used to manage hardware equipment used within the network infrastructure.

The page displays equipment information including:

- ID
- Equipment Name
- Manufacturer
- Provisioning URL
- Status
- Actions

![Equipment](/img/equipment.png)

## Equipment List

The equipment table provides an overview of the hardware configured in the system.

Each equipment record displays its manufacturer, provisioning URL, and current status.

The status shown in the system indicates whether the equipment is **Active**.

## Search

Users can search for equipment by equipment name.

The search controls include:

- Search by Equipment Name
- Search field

## Add Equipment

The **Add Equipment** button allows users to create a new equipment record.

## Edit Equipment

The **Edit** action allows users to modify an existing equipment record.

## Delete Equipment

The **Delete** action allows users to remove an equipment record from the system.

## Purpose

The Equipment module provides centralized management of network hardware and its associated configuration information.
