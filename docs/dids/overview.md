# DIDs

## Overview

The DIDs section provides a dashboard for managing Direct Inward Dialing (DID) numbers used within the network.

The page displays DID numbers along with their associated customer and provider information.

![DIDs](/img/dids.png)

## DID Information

The DID list provides information such as:

- DID Number
- Customer ID
- Customer Name
- Provider

The system supports pagination for navigating through the available DID records.

## Search

Users can search for DIDs using:

- DID number
- Search text
- Wildcard search using `%`

The provider filter can also be used to display DIDs associated with a particular provider.

## DID Actions

The action menu provides several operations:

- Add DID Number
- Upload DID File
- Assign DIDs
- Export DIDs
- Display Logs

## Add DID Number

The **Add DID Number** option allows users to add a new DID number to the system.

## Upload DID File

Users can upload a DID file to add multiple DID records.

## Assign DIDs

The **Assign DIDs** option is used to associate selected DID numbers with customers.

## Export DIDs

The **Export DIDs** option allows users to export DID information.

## Display Logs

The **Display Logs** option provides access to DID-related activity or processing logs.

## Purpose

The DIDs module provides centralized management of DID numbers and their customer and provider assignments.
