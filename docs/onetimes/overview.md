# One-time Payments

## Overview

The One-time Payments section is used to manage charges or items that need to be considered separately from the customer's regular recurring billing cycle.

The section displays one-time payment details including:

- Customer ID
- Customer Name / Item Description
- One-Time Date
- Unit Price
- Quantity
- Section
- Actions

Users can search for one-time payment records by customer name and can edit existing records.

## One-time Payment List

The payment list provides an overview of all configured one-time charges.

Each record contains the customer information along with the item description, date, price, quantity, and billing section.

![One-time Payments](/img/onetimes.png)

## Search

The search functionality allows users to find a specific record using the customer name.

## Edit One-time Payment

The **Edit** button allows users to modify an existing one-time payment record.

## Purpose

The One-time Payments module helps manage additional charges that should be included in the next invoice cycle without changing the customer's regular recurring services.
