# Add One-time Payment

## Overview

The **Add One-time Payment** feature allows users to create a new one-time charge for a customer.

To add a one-time payment, click the **Add Onetime Payment** button from the One-time Payments page.

![Add One-time Payment](/img/add-onetime-payment.png)

## Payment Details

The form contains the following fields:

### One-Time Type

Select the type of one-time charge.

The available example shown in the system is:

- One-Off: Charge

### One-Time Date

Select the date on which the one-time charge should be applied.

### For Customer

Select the customer for whom the charge is being created.

### Item Description

Enter a description of the item or service being charged.

### Unit Price / Lumpsum Discount

Enter the unit price or applicable lumpsum discount.

### Quantity / Percentage Discount

Enter the quantity or percentage discount depending on the selected payment type.

### Total Amount

The system displays the calculated total amount based on the entered values.

## Adding the Payment

After entering all required information:

1. Select the one-time payment type.
2. Select the date.
3. Select the customer.
4. Enter the item description.
5. Enter the price or discount.
6. Enter the quantity or percentage discount.
7. Verify the **Total Amount**.
8. Click **Add Onetime Payment**.

## Purpose

This feature allows administrators to add additional customer-specific charges that can be considered during the next invoice cycle.
