# Rate Comparison

## Overview

The Rate Comparison module allows users to upload rate files and compare the rates contained in them.

The module supports uploading two CSV files for comparison and provides an option to update the database with the resulting rates.

![Rate Comparison](/img/rate-comparison.png)

## Upload Rate Files

The **Upload Rate Files** section provides two file inputs:

- File 1
- File 2

Users can select the two CSV files that need to be compared.

## Run Comparison

After selecting both files, click **Run Comparison**.

The system processes the uploaded files and displays the comparison results.

## Push to Allrates

The **Push to Allrates** option can be used to update the rate database with the uploaded rate information.

## Comparison Results

The results section displays rate comparison information such as:

- Code
- Destination
- Rate (pence)
- Extra (pence)

The system also provides an **All Rates (DB)** view containing the rates currently stored in the database.

## Search Results

Users can search the comparison results using the search field.

## Purpose

The Rate Comparison module simplifies the process of comparing rate files and maintaining updated rate information in the database.
