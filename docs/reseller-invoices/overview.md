# Reseller Invoices

The Reseller Invoices section is used to manage invoices associated with distributors or resellers in the Hexa Billing System.

![Reseller Invoices](/img/reseller-invoices.png)

*Figure: Reseller Invoice screen for selecting a distributor, invoice month, and processing invoices.*

## Invoice Management

The Reseller Invoices section allows users to:

- Select a distributor.
- Select the invoice month.
- Customize an invoice.
- Process invoices.
- Search invoices by customer name or ID.
- Review available invoices.

## Selecting a Distributor

Users can select a distributor from the **Distributor** dropdown.

The selected distributor determines the reseller account for which invoice information is displayed.

## Invoice Month

The **View Monthly Invoices** option allows users to select the month for which reseller invoice information should be displayed.

## Customizing an Invoice

The **Customize Invoice** option allows users to modify invoice information for the selected distributor before processing.

## Processing Invoices

The **Process Invoices** button is used to process invoices for the selected processing month.

Users can select the required month and start the invoice processing operation.

## Searching Invoices

The search field allows users to search for invoices using:

- Customer name
- Customer ID

## Purpose

The Reseller Invoices section helps users manage distributor-specific billing information and process invoices efficiently.
