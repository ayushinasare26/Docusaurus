# Connect to Xero

The **Connect to Xero** button allows the Hexa Billing System to integrate with the Xero accounting platform.

## Purpose

Once connected, accounting data can be synchronized automatically between Hexa and Xero, reducing manual data entry.

## Benefits

- Synchronize invoices
- Export customer information
- Record payments
- Maintain financial consistency
- Simplify bookkeeping
