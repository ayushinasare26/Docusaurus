# Dashboard

## Overview

The Dashboard serves as the homepage of the Hexa Billing System and provides users with a real-time summary of the organization's billing, customer, revenue, and call performance.

It is designed to help users quickly understand the overall business status without navigating through multiple modules.

The dashboard contains interactive charts, summary cards, customer insights, and performance metrics that can be filtered by customer, month, or year.

![Dashboard Overview](/img/dashboard-overview.png)

*Figure: Main Hexa Billing System dashboard showing customer statistics, monthly sales, revenue, and analytics.*

## Dashboard Layout

The dashboard consists of the following sections:

1. Customer Summary Cards
2. Monthly Sales Chart
3. Revenue Progress
4. Call Volume Overview
5. Customer Lifetime Value (CLV)
6. Top Customers by Revenue
7. Customer Demographics Map

Each section provides valuable business insights and supports data-driven decision-making.
