# Package Groups

The Package Groups section allows users to view and manage groups of products or services used within the Hexa Billing System.

![Package Groups](/img/package-groups.png)

*Figure: Package Groups displaying package group IDs, package names, group codes, creation dates, and available actions.*

## Package Group Information

The Package Groups table displays:

- Package Group ID
- Package Name
- Group Codes
- Created Date
- Available actions

## Group Codes

Group codes identify the services or products associated with a particular package group.

A package group may contain multiple group codes.

## Adding a Package Group

The **Add New** button allows users to create a new package group.

Users can provide the required package information and associated group codes.

## Package Group Actions

The Actions column allows users to manage existing package groups.

Users can:

- Edit a package group.
- Delete a package group.

## Pagination

The package group list supports pagination for navigating through multiple package groups.

## Purpose

Package Groups help organize related products and services into manageable groups for billing and service management.
